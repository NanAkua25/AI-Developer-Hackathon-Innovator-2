# ? PropAgent AI

PropAgent AI is a commercial real estate due diligence dashboard built with Python and Streamlit.

The application helps automate lease agreement analysis by identifying financial risk clauses and generating underwriting metrics in seconds.

## Features

- ? Upload commercial lease agreements (PDF)
- ? Detect financial risk clauses
- ? Calculate Net Operating Income (NOI)
- ? Project 10-year NOI growth
- ?? Flag high-risk lease language

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- PyPDF

## Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Project Motivation

Commercial real estate professionals spend significant time reviewing lease agreements for financial risks. PropAgent AI streamlines this process by automatically identifying risk-related clauses and generating financial projections.
